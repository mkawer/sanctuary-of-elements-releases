# Sanctuary of Elements

Playtest de ARPG isométrico: jogue solo ou com até 4 pessoas, com Windows e Mac
na mesma party.

## Baixar o launcher

- [Windows](https://github.com/mkawer/sanctuary-of-elements-releases/releases/latest/download/Sanctuary-Launcher-Windows.zip)
- [macOS — Intel e Apple Silicon](https://github.com/mkawer/sanctuary-of-elements-releases/releases/latest/download/Sanctuary-Launcher-macOS.zip)
- [Jogo completo, versões e novidades](https://github.com/mkawer/sanctuary-of-elements-releases/releases/latest)

Extraia o ZIP. No Windows, abra **Launcher.exe** e mantenha **Launcher.pck** ao
lado dele. No Mac, arraste **Sanctuary Launcher.app** para Aplicativos e abra.
Clique em **Instalar o jogo** e depois em **Jogar**. Nas próximas versões, clique
em **Atualizar**: não é necessário receber outro ZIP nem instalar Godot.

O launcher preserva o progresso e permite jogar a instalação existente quando
o servidor de downloads não estiver disponível. A atualização baixa o pacote
completo automaticamente; ainda não usa patches diferenciais.

**Mac:** build de teste sem notarização Apple. Se o sistema bloquear a primeira
abertura, use Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim,
apenas para o download oficial. Hosting online no Mac requer macOS 15 ou mais
recente; Macs anteriores compatíveis com o jogo podem entrar numa sala Windows.

## Jogar com amigos

Dentro do jogo, **F9** abre a sala. Uma pessoa cria a sala online e compartilha
o convite em particular. É possível iniciar com 1, 2, 3 ou 4 jogadores. Todos
devem estar na mesma versão. Não publique convites ou saves neste repositório.

[Wiki — itens, conjuntos, classes e quests](https://sanctuary-of-elements-wiki.kawfe.chatgpt.site/)

Este repositório contém apenas downloads oficiais. O código do projeto é mantido
separadamente.
